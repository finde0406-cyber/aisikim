등록 화면에 그대로 복사해 쓰는 자료. 첫 상품은 **통합 스타터팩(50개, 24,900원)** — 분량이 가장 두꺼워 전자책 심사 기준에 안전하고 객단가도 높다.

---

## ⚠️ 심사 반려 방지 3원칙 (가장 중요)

1. **외부 링크·외부 채널 언급 금지** — 상세설명·파일 어디에도 aisikim.com, 스레드, 이메일 주소를 넣지 않는다 (크몽은 외부 거래 유도를 엄격히 금지, 즉시 반려 사유)
2. 판매 파일(PDF) 안의 사이트 링크·연락처도 크몽용 버전에서는 제거 필요 → **크몽 전용 PDF는 요청 시 제가 재생성**
3. 과장 표현 금지 — "무조건", "100% 수익" 같은 문구 사용 안 함 (아래 문안은 이미 반영됨)

## 1. 서비스 제목 (선택 1)

- A안: `AI에게 일 시키는 법, 복사해서 바로 쓰는 작업지시서 50개를 드립니다`
- B안: `ChatGPT가 뻔한 답만 할 때, 상황별 작업지시서 50개로 해결해 드립니다`

## 2. 카테고리

전자책 → 자기계발/취미 (또는 "IT·프로그래밍 전자책"이 보이면 그쪽) — 등록 화면에서 "AI/ChatGPT" 관련 세부 카테고리가 있으면 그것 우선

## 3. 가격

- 기본 패키지: **24,900원** (사이트와 동일가 — 채널 간 가격 신뢰 유지)
- 패키지 3단계를 요구하면: STANDARD 24,900(전체 50개) 하나만 활성화하거나, BASIC 9,900(한 분야 10개 발췌) / STANDARD 24,900(50개 전체) 구성

4. "서비스 등록" → 위 1~5 자료 붙여넣기 → 파일 업로드(크몽 전용 PDF — 제가 재생성해드림) → 제출
