# AI시킴 자산 링크 레지스트리 v1

## 1. 문서 목적
이 문서는 AI시킴에서 실제로 발송하거나 연결해야 하는 핵심 자산 링크를 한 곳에서 관리하기 위한 문서입니다.  
샘플팩, 스타터팩, 이메일 신청 폼, 결제 링크, 발신 메일 주소를 확정하는 순간 이 문서에 값을 입력하고, 이후 Claude Code가 서비스 연결 작업을 반영할 때 기준값으로 사용합니다.

---

## 2. 입력 원칙
- 링크는 최종 사용자에게 실제로 발송 가능한 상태일 때만 입력합니다.
- 테스트 링크와 실운영 링크를 구분해 적습니다.
- 같은 파일을 교체하더라도 가능하면 링크는 유지하는 방식이 좋습니다.
- Notion 링크는 `공개 읽기 전용` 상태를 확인한 뒤 입력합니다.

## 7. Claude Code 연결 전 체크

## 8. 현재 판단
이 문서는 새로운 기획 문서가 아니라, `문서 자산 완성 → 실제 링크 입력 → 서비스 연결` 단계로 넘어가기 위한 운영용 브리지 문서입니다.
