# AI시킴 블로그/콘텐츠 집중팩 제작 기준 v1

## 1. 문서 목적
이 문서는 `블로그/콘텐츠 집중팩`을 실제 고객 판매용으로 제작할 때 필요한 기준을 정리한 문서입니다.

---

## 2. 왜 블로그/콘텐츠 집중팩이 중요하나
- 블로그 운영자, 1인 사업자, 콘텐츠 마케터 수요와 직접 연결된다.
- 글 초안, 제목, 구조, 판매 문구는 반복 사용 빈도가 높다.
- “시간 절약”과 “콘텐츠 품질 개선”이라는 구매 이유가 명확하다.

---

## 3. 이 집중팩의 핵심 약속
이 상품은 글 문장 몇 개를 던져주는 자료가 아니라,
`콘텐츠 아이디어를 더 빨리 꺼내고, 읽히는 구조로 정리하고, 목적에 맞게 다듬도록 돕는 패키지`
여야 한다.

고객이 느껴야 하는 핵심은 아래다.
- 글 초안이 훨씬 빨라진다
- 제목과 구조가 더 선명해진다
- 정보형 글, 판매형 글, 짧은 홍보 문구까지 한 흐름으로 연결된다

---

## 4. 권장 본문 구성

### 4.1 핵심 10개
1. 블로그 글의 첫 구조를 잡고 싶을 때
2. 글 제목 후보를 여러 방향으로 뽑고 싶을 때
3. 정보형 글을 더 구체적으로 확장하고 싶을 때
4. 소제목 구조를 더 읽기 좋게 정리하고 싶을 때
5. 판매형 콘텐츠 문구를 자연스럽게 녹이고 싶을 때
6. 같은 내용을 짧은 SNS용 문구로 바꾸고 싶을 때
7. 독자나 대상에 맞게 톤을 바꾸고 싶을 때
8. 읽기 쉬운 구조로 다시 나누고 싶을 때
9. 추상적인 표현을 실제 예시 중심으로 바꾸고 싶을 때
10. 더 설득력 있게 다시 쓰고 싶을 때

### 4.2 보조 5개
- 원하는 결과물 형식을 먼저 고정하고 싶을 때
- 빠진 핵심 요소가 있는지 점검하고 싶을 때
- 수정 요청을 어떻게 이어갈지 설계하고 싶을 때
- 검수 질문을 어떻게 던질지 정리하고 싶을 때
- 전체 작업 흐름을 한 번에 설계하고 싶을 때

---

## 5. 변수 반응형 기준
- 현재 막힌 부분
- 원하는 결과물 형식
- 사용할 AI 도구
- 원하는 톤/스타일

각 작업지시서는 위 변수를 흡수하는 슬롯과 보정 가이드를 포함해야 한다.

---

## 6. 판매 문구 방향

### 좋은 방향
- 글 초안부터 제목, 구조, 수정까지 한 흐름으로 이어지는 콘텐츠 작업지시서
- 블로그, 뉴스레터, SNS, 판매 문구까지 한 번에 응용할 수 있는 패키지
- 읽히는 글로 다듬고 싶은 사람에게 바로 도움이 되는 실전형 자료

### 피해야 하는 방향
- AI가 알아서 콘텐츠를 다 만들어준다
- 이 팩만 있으면 무조건 조회수가 오른다
- 복붙만 하면 바로 완성된다

---

## 7. 최종 기준
블로그/콘텐츠 집중팩은 단순한 글쓰기 문장 모음이 아니라,
`콘텐츠를 더 빨리 만들고, 더 읽히게 다듬고, 더 목적에 맞게 전환시키도록 돕는 반응형 패키지`
처럼 느껴져야 한다.
