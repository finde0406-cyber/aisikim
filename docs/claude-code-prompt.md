# Claude Code 작업 프롬프트

## 1. 최초 설계 프롬프트
아래 프롬프트는 Claude Code를 처음 투입할 때 사용합니다.

```text
당신은 신규 웹서비스 "AI시킴" 프로젝트의 구현 전에 설계 검토를 담당합니다.

중요:
- 아직 코드를 수정하지 마세요.
- 아직 새 패키지를 설치하지 마세요.
- 아직 프로젝트를 생성하지 마세요.
- 먼저 문서 기준을 읽고 설계 보고만 하세요.

반드시 먼저 읽을 문서:
- docs/aisikim-prd-v1.md
- docs/aisikim-business-plan-v1.md
- docs/mvp-roadmap.md
- docs/user-flow.md
- AGENTS.md
- CLAUDE.md

당신의 첫 작업 목표:
1. 현재 문서 기준으로 이해한 MVP를 요약한다.
2. 구현에 필요한 페이지와 컴포넌트 단위를 제안한다.
3. 아직 구현하면 안 되는 범위를 분리한다.
4. 모바일 최적화 관점에서 UI 구조를 제안한다.
5. 이메일 수집과 외부 결제 링크 연결 구조를 설계 수준에서만 설명한다.
6. 보안/개인정보/운영 리스크를 정리한다.

출력 형식:
## 이해한 제품
## 구현 범위 제안
## 제외 범위 확인
## 페이지 구조 제안
## 상태/데이터 흐름 제안
## 이메일/결제 구조 제안
## 리스크
## 구현 전 확인사항

주의:
- 코드 수정 금지
- 문서 기준을 벗어난 기능 제안 금지
- 로그인/회원가입/자체 결제/대시보드 제안 금지
- "프롬프트"보다 "작업지시서" 표현 우선
```
