# AI시킴 콘텐츠 품질 기준

## 1. 문서 목적
이 문서는 AI시킴에서 사용자에게 제공하는 무료 작업지시서, 샘플팩, 유료 스타터팩, 향후 딥팩의 품질 기준을 정의합니다.  
서비스를 단순히 "기능이 있는 상태"로 공개하지 않고, 사용자가 실제로 돈을 내고도 만족할 수 있는 수준으로 만들기 위한 내부 기준 문서입니다.

## 2. 핵심 원칙
### 2.1 무료도 약하면 안 된다
- 무료 결과 1개는 서비스 품질을 증명하는 첫 결과물이다.
- 사용자가 "생각보다 바로 쓸 만하다"라고 느껴야 한다.
- 무료 결과가 약하면 샘플팩과 유료팩 전체 신뢰도도 함께 떨어진다.

### 2.2 유료는 분명히 달라야 한다
- 유료 상품은 단순히 길거나 개수가 많은 자료가 아니다.
- 무료보다 더 정확하고, 더 실전적이며, 결과물을 끝까지 끌고 갈 수 있어야 한다.
- 사용자가 "이건 돈 내고 살 만하다"라고 느끼는 명확한 차이가 있어야 한다.

### 2.3 문장 모음이 아니라 실행 세트여야 한다
- AI에게 한 번 던지는 문장 모음처럼 보이면 안 된다.
- 각 작업지시서는 목적, 사용 시점, 후속 질문, 수정 요청, 검수 요청까지 포함한 실행 세트여야 한다.

### 2.4 사용자에게 설명도 함께 줘야 한다
- 좋은 작업지시서를 주는 것만으로는 부족하다.
- 언제 쓰는지, 무엇을 바꾸면 되는지, 어떤 순서로 써야 하는지도 함께 안내해야 한다.

## 3. 무료 기본 작업지시서 1개 기준
### 3.1 역할
- 서비스 품질을 짧은 시간 안에 증명한다.
- 사용자가 "이렇게 물어보면 되는구나"를 배우게 한다.
- 샘플팩이나 유료팩을 더 보고 싶게 만든다.

### 3.2 최소 품질 기준
- 사용자의 선택값이 분명히 반영되어야 한다.
- 목적, 막힌 부분, 원하는 결과물, 사용할 AI 도구, 원하는 스타일이 자연스럽게 녹아 있어야 한다.
- 복사 후 바로 붙여 넣어 쓸 수 있어야 한다.
- 너무 짧거나 뻔한 일반론으로 끝나면 안 된다.

### 3.3 권장 구조
1. 작업 배경
2. 현재 막힌 부분
3. 요청 사항
4. 작업 조건
5. 시작 전 확인사항

### 3.4 금지 기준
- 한두 줄짜리 추상적 문장
- 사용자 맥락이 거의 반영되지 않은 범용 답변
- 어떤 AI에 넣어도 되는지 맥락이 없는 문장

## 4. 샘플팩 5개 기준
### 4.1 역할
- 무료 결과 1개보다 한 단계 더 깊은 품질을 보여준다.
- 사용자가 "이 서비스는 진짜 더 써볼 만하다"라고 느끼게 한다.
- 유료 구매 전 마지막 신뢰 형성 구간이다.

### 4.2 구성 원칙
- 초기 MVP 핵심 카테고리와 직접 연결되어야 한다.
- 서로 다른 상황에서 바로 써볼 수 있게 배치한다.
- 무료 결과보다 더 실전적인 흐름이 보여야 한다.

### 4.3 각 샘플에 포함할 요소
1. 이 작업지시서가 필요한 상황
2. 바로 복사할 본문
3. 사용 전 바꿔야 할 부분
4. 후속 질문 1개 이상
5. 결과가 별로일 때 수정 요청 예시 1개

### 4.4 샘플팩이 부족하면 안 되는 이유
- 샘플팩이 약하면 사용자는 스타터팩도 약할 것이라고 예상한다.
- 따라서 샘플팩은 "무료라서 대충"이 아니라 "유료를 미리 믿게 만드는 자료"여야 한다.

## 5. 스타터팩 50개 기준
### 5.1 역할
- AI시킴의 첫 유료 구매 상품
- 여러 카테고리를 넓게 경험하는 입문용 유료 상품
- 사용자가 AI시킴 방식이 자신에게 맞는지 시험 구매하게 하는 상품

### 5.2 기본 구성
1. 블로그/콘텐츠 작업지시서 10개
2. 업무/보고서 작업지시서 10개
3. 앱/웹사이트 개발 작업지시서 10개
4. 결과물 검수/수정 작업지시서 10개
5. 공통 AI 활용/작업설계 작업지시서 10개

### 5.3 각 작업지시서에 반드시 포함할 요소
1. 목적
2. 언제 쓰는지
3. 어떤 상황에 맞는지
4. 바로 복사해서 쓸 본문
5. 사용자가 바꿔야 할 변수
6. 후속 질문 예시
7. 수정 요청 예시
8. 검수 요청 예시

### 5.4 유료 상품 설명서에 포함할 요소
1. 이 상품을 어떻게 활용하면 좋은지
2. 어떤 순서로 쓰면 좋은지
3. 카테고리별 특징
4. 복사 후 반드시 바꿔야 할 부분
5. AI 답변이 별로일 때 재시도하는 방법

### 5.5 금지 기준
- 문장만 나열된 묶음
- 개수만 많고 설명이 없는 자료
- 무료 결과와 체감 차이가 거의 없는 자료
- 후속 질문, 수정 요청, 검수 요청이 빠진 자료

## 6. 향후 딥팩 기준
### 6.1 역할
- 본격 수익화 상품
- 특정 분야를 실제로 많이 쓰는 사용자가 더 깊게 구매하는 상품

### 6.2 딥팩이 스타터팩보다 더 좋아야 하는 점
- 더 구체적인 상황별 분화
- 더 긴 사용 흐름
- 더 강한 실무 밀도
- 더 풍부한 수정/검수 예시
- 초보자용이 아니라 실사용자용 만족도까지 고려

## 7. 품질 점검 체크리스트
### 7.1 무료 결과
- 내 선택값이 반영된 느낌이 드는가
- 바로 복사해서 쓸 수 있는가
- 너무 일반적이지 않은가

### 7.2 샘플팩
- 무료 결과보다 한 단계 더 좋다고 느껴지는가
- 바로 써보고 싶어지는가
- 유료팩에 대한 기대가 생기는가

### 7.3 유료팩
- 실제로 결과물 완성까지 끌고 갈 수 있을 것 같은가
- 돈값 한다는 느낌이 드는가
- 사용법 설명이 충분한가
- 단순히 많이 주는 것처럼 보이지 않는가

## 8. 최종 기준
AI시킴의 콘텐츠는 "작동하는 서비스용 텍스트"가 아니라, 사용자가 실제로 복사해서 써보고 결과가 달라졌다고 느끼게 만드는 실전 자료여야 합니다.  
무료는 증명, 샘플팩은 신뢰, 스타터팩은 입문 구매, 딥팩은 본격 수익화라는 기준을 계속 유지합니다.
