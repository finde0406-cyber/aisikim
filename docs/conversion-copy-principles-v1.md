# AI시킴 구매 욕구 설계 원칙 v1

## 1. 문서 목적
이 문서는 AI시킴에서 사용자가 무료 결과를 본 뒤 샘플팩을 받고, 결국 스타터팩까지 구매하고 싶어지게 만드는 카피와 전환 원칙을 정리한 문서입니다.  
핵심은 과장이나 낚시가 아니라, `실제 체감 가치 + 다음 단계가 궁금해지는 구조`를 만드는 것입니다.

## 2. 기본 원칙

### 2.1 억지 판매보다 체감이 먼저다
- 좋은 무료 결과와 좋은 샘플팩이 먼저다
- 판매 카피는 체감을 더 잘 보이게 만드는 역할이다

### 2.2 랜덤박스의 심리는 참고하되, 도박성은 버린다
- `다음 결과가 궁금해지는 구조`
- `지금보다 더 좋은 버전이 있을 것 같은 기대`
- `한 번 더 써보고 싶어지는 흐름`

하지만 아래는 금지한다.
- 속임수
- 과장
- 실제보다 훨씬 좋아 보이게 만드는 표현

### 2.3 AI시킴은 신뢰 기반 서비스다
- 무료/유료 경계를 분명히 해야 한다
- 지금 열려 있는 것과 아직 안 열려 있는 것을 정확히 보여줘야 한다

## 3. 단계별 감정 설계

### 3.1 무료 결과에서 만들어야 하는 감정
- `이거 생각보다 좋네`
- `이렇게 시키면 되는구나`
- `내 선택이 반영된 느낌이 있네`

### 3.2 샘플팩에서 만들어야 하는 감정
- `한 개가 아니라 여러 상황에서도 쓸 수 있네`
- `이 서비스는 진짜 더 써볼 만하다`
- `다음 작업지시서도 궁금하다`

### 3.3 유료 스타터팩에서 만들어야 하는 감정
- `무료 1개와는 확실히 다르다`
- `이건 결과를 완성하는 흐름을 주는구나`
- `돈 내고 사도 아깝지 않겠다`

## 4. 카피 방향 원칙

### 4.1 무료 결과 카피
권장 방향:
- 지금은 기본 작업지시서 1개만 열려 있습니다
- 이 결과를 바탕으로 더 이어가고 싶다면
- 다음 단계 작업지시서도 확인해보세요

의도:
- 지금 본 결과가 시작점이라는 점을 알려줌

### 4.2 샘플팩 카피
권장 방향:
- 샘플 5개 더 열어보기
- 다른 상황에서도 바로 써볼 수 있는 작업지시서 5개
- 지금 결과보다 더 실전적인 예시 먼저 받아보기

의도:
- 단순한 “무료 자료”가 아니라 “더 보게 만드는 경험”으로 위치시킴

### 4.3 스타터팩 카피
권장 방향:
- 기본 1개에서 끝나지 않도록
- 후속 질문, 수정 요청, 검수 질문까지 이어지는 전체 흐름
- 결과물을 완성하기 위한 단계별 작업지시서 50개

의도:
- 자료 양보다 완성 흐름을 강조

## 5. 꼭 살리고 싶은 심리 구조

### 5.1 지금 받은 것보다 더 좋은 다음 단계가 있을 것 같은 느낌
예:
- 지금은 시작용 작업지시서 1개만 열려 있습니다
- 더 완성도 있는 흐름은 다음 단계에서 이어집니다

### 5.2 지금 멈추기 아까운 느낌
예:
- 여기서 끝내기보다 샘플 5개를 더 받아보세요
- 같은 목적이라도 다른 상황에서 더 써볼 수 있습니다

### 5.3 유료가 자연스러운 확장처럼 느껴지게 하기
예:
- 무료는 시작
- 샘플팩은 체험
- 스타터팩은 입문용 유료 도구

## 6. 절대 피해야 할 카피
- 이거 하나면 다 해결됩니다
- 무조건 결과가 좋아집니다
- 지금 안 사면 손해입니다
- 무료보다 훨씬 대단한 비밀 자료

이런 표현은 신뢰를 깎습니다.

## 7. 결과 페이지 전환 원칙
- 샘플팩 CTA를 유료보다 먼저 강조
- 스타터팩 CTA는 유지하되 소프트하게
- 사용자가 `다음 단계`를 스스로 선택하게 만들 것

## 8. 스타터팩 페이지 전환 원칙
- 스타터팩은 입문용 유료 상품으로 보이게
- 여러 카테고리를 넓게 경험하는 상품이라는 점을 분명히
- 부담보다 `시험 구매해볼 만한 상품`처럼 느껴지게

## 9. 최종 기준
좋은 전환 카피는 사람을 속여서 결제시키는 것이 아니라,  
이미 느낀 체감 가치를 더 분명히 이해하게 만들고, 다음 단계가 자연스럽게 궁금해지게 만드는 것입니다.  
AI시킴의 전환 설계는 항상 `신뢰 → 체감 → 확장` 순서를 유지해야 합니다.
