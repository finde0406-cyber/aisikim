# 배포 체크리스트

## 1. 목적
이 문서는 AI시킴을 실제 배포할 때 확인해야 할 항목을 정리한 체크리스트입니다. 현재 단계에서는 실행하지 않고, 향후 배포 준비 기준으로만 사용합니다.

## 2. Vercel 배포 체크리스트
- 배포 대상 브랜치 확인
- 환경 설정 확인
- 빌드 명령 확인
- 오류 페이지 기본 동작 확인
- 모바일 첫 화면 렌더링 확인

## 3. 도메인 연결 체크리스트
- 도메인 구매 여부 확인
- DNS 연결 정보 확인
- HTTPS 적용 확인
- 루트 도메인과 www 리다이렉트 정책 확인

## 4. 환경변수 체크리스트
- 이메일 폼 또는 연동 서비스 키 확인
- 외부 결제 링크 URL 확인
- 분석 도구 키 확인
- 운영/테스트 값 구분 확인

## 5. 이메일 폼 연결 확인
- 이메일 제출 동작 확인
- 동의 문구 노출 확인
- 제출 후 안내 문구 확인
- 실제 수신 테스트 확인

## 6. 결제 링크 확인
- 각 결제 링크가 올바른 상품으로 연결되는지 확인
- 가격 표기가 일치하는지 확인
- 결제 후 자료 수령 안내가 분명한지 확인
- 환불 및 디지털 상품 안내 문구 확인

## 7. 모바일 확인
- iPhone 계열 화면 확인
- Android 계열 화면 확인
- 주요 버튼 터치 영역 확인
- 긴 문구 줄바꿈 확인
- 결과 복사 동작 확인

## 8. GA4 / Search Console 연결 검토
- GA4 연결 여부
- 핵심 이벤트 정의 여부
- Search Console 등록 여부
- 사이트맵 및 기본 메타 점검 여부

## 9. 최종 점검
- PRD 범위와 실제 구현 범위가 일치하는가
- 무료/유료 전환 흐름이 끊기지 않는가
- 개인정보 및 동의 문구가 빠지지 않았는가
- 외부 결제와 자료 제공 안내가 일관적인가
