# AI시킴 최종 문서 자산 인덱스 v1

## 1. 문서 목적
이 문서는 AI시킴 출시 전까지 준비해야 하는 핵심 문서 자산을 한 번에 확인하기 위한 인덱스 문서입니다.  
기획, 상품, 발송, 운영, 자동화 문서를 영역별로 묶고, 현재 어떤 단계까지 준비되었는지 빠르게 파악할 수 있게 정리합니다.

---

## 2. 현재 문서 자산 상태 요약

### 2.1 기획 문서
- 제품/사업/수익화/로드맵 문서는 기본 기준본이 모두 준비됨
- MVP 범위와 제외 범위가 문서상으로 고정됨

### 2.2 상품 문서
- 샘플팩 5개 초안 있음
- 샘플팩 발송용 정리본 있음
- 샘플팩 PDF 최종 문안 있음
- 샘플팩 Notion 최종 문안 있음
- 스타터팩 50개 분배표 있음
- 우선 제작 15개 프리미엄 초안 있음
- 스타터팩 PDF 최종 문안 있음
- 스타터팩 Notion 최종 문안 있음
- 스타터팩 사용 가이드 있음

### 2.3 운영 문서
- 이메일 발송 운영 기준 있음
- 자동화 구조 있음
- 운영값 체크리스트 있음
- 운영값 질문표 있음

### 2.4 아직 실제 값 입력이 필요한 항목
- 무료 신청 폼 실제 링크
- 샘플팩 PDF 실제 링크
- 샘플팩 Notion 실제 링크
- 스타터팩 PDF 실제 링크
- 스타터팩 Notion 실제 링크
- 스타터팩 사용 가이드 실제 링크
- 실제 발신 메일 주소
- 유료 결제 링크

## 8. 현재 판단
지금 상태는 `문서가 부족한 상태`가 아니라 `문서는 거의 다 있는 상태`입니다.  
이제부터는 새 문서 종류를 늘리기보다, 이미 만든 문서를 실제 발송 자산과 실제 운영값으로 연결하는 단계가 우선입니다.
