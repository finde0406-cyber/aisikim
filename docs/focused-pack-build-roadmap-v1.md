# AI시킴 집중팩 제작 로드맵 v1

## 1. 문서 목적
이 문서는 실제 판매 가능성이 높은 집중팩부터 어떤 순서로 실물 자산화해야 하는지, 제작 관점에서 정리한 로드맵입니다.

---

## 2. 제작 우선순위

### 1단계
앱/웹사이트 개발 집중팩

#### 이유
- 고객 문제의 선명도가 높다.
- 지불 의사가 생기기 쉬운 분야다.
- 무료 결과와 유료팩 차이를 보여주기 쉽다.
- AI시킴의 `선택형 → 실전 작업지시서` 구조와 잘 맞는다.

### 2단계
업무/보고서 집중팩

#### 이유
- 직장인/실무 수요와 직접 연결된다.
- 반복 사용 가능성이 높다.
- 상사 보고, 기획서, 실행안 같은 상황은 구매 이유가 명확하다.

### 3단계
블로그/콘텐츠 집중팩

#### 이유
- 수요는 충분하지만 경쟁 대안이 많다.
- 카피와 상품 설명 완성도가 더 중요하다.
- 개발/업무보다 뒤로 두되, 완성도는 높게 가져가야 한다.

---

## 3. 각 집중팩 제작 순서

### 공통 제작 단계
1. 해당 카테고리 핵심 10개 선별
2. 관련 검수/수정 작업지시서 3개 선별
3. 공통 AI 활용 보조 작업지시서 2개 선별
4. PDF 최종 문안 정리
5. Notion 최종 문안 정리
6. 사용 가이드 작성
7. 구매 후 발송 메일 작성

---

## 4. 실제 판매자 관점 최종 판단
지금 가장 상품성이 높은 구조는 다음과 같다.

1. 무료 진단
2. 샘플팩
3. 개발 집중팩 판매
4. 업무 집중팩 판매
5. 콘텐츠 집중팩 판매
6. 이후 통합 스타터팩 번들 제안

즉, 판매 페이지도 이 순서를 기준으로 다시 설계하는 편이 더 좋다.
