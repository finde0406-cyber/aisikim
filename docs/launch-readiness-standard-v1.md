# AI시킴 출시 가능 기준서 v1

## 1. 문서 목적
이 문서는 AI시킴을 실제로 판매 가능한 상태로 판단하기 위한 `출시 가능 기준서`입니다.  
“이 정도면 됐다” 수준이 아니라, 실제로 사용자에게 돈을 받고 제공해도 신뢰를 해치지 않는 상태인지 점검하는 기준으로 사용합니다.

---

## 2. 판단 원칙
- 보기 좋은 문서가 많다고 출시 가능한 것은 아닙니다.
- 무료 결과, 샘플팩, 유료팩, 발송 경험, 운영 연결이 모두 일정 기준을 넘어야 합니다.
- 부분적으로만 좋은 상태는 출시 가능 상태가 아닙니다.
- 특히 유료 상품은 `구성`, `품질`, `전달 경험`, `사용 가이드`가 함께 완성되어야 합니다.

---

## 3. 무료 결과 출시 기준
아래 항목을 모두 만족해야 합니다.

1. 사용자가 결과를 보고 “생각보다 바로 써볼 만하다”는 반응을 가질 것
2. 선택값(category, blocker, output, ai_tool, style)이 눈에 띄게 반영될 것
3. 단순 문장 1~2개가 아니라 복사 가능한 작업지시서 블록일 것
4. 후속 사용을 자연스럽게 유도할 것
5. 무료치고 괜찮은 수준이 아니라, 서비스 전체 신뢰를 만들 수 있는 수준일 것

### 현재 판단
- 기준에 꽤 가까워졌음
- 하지만 실제 사용자 3~5명 반응 테스트는 아직 필요

---

## 4. 샘플팩 출시 기준
아래 항목을 모두 만족해야 합니다.

1. 샘플 5개가 서로 역할이 분명히 다를 것
2. 샘플 5개만 받아도 “이 서비스는 진짜 도움 된다”는 느낌이 날 것
3. 각 샘플이 목적, 사용 시점, 본문, 후속 질문, 수정 요청, 검수 요청을 포함할 것
4. PDF와 Notion 둘 다 읽기/복사 경험이 좋아야 할 것
5. 발송 메일이 파일만 던지는 수준이 아니라 사용 안내를 포함할 것

### 현재 판단
- 문서 기준으로는 거의 실전 단계
- 실제 PDF/Notion 실물 제작과 링크 생성이 남아 있음

---

## 5. 유료 스타터팩 출시 기준
아래 항목을 모두 만족해야 합니다.

1. 사용자가 “문장 50개”가 아니라 “실제 결과를 완성하는 도구”라고 느낄 것
2. 각 작업지시서가 목적, 시점, 본문, 후속 질문, 수정 요청, 검수 요청을 포함할 것
3. 최소한 대표 15개가 아니라 전체 50개가 같은 품질 기준으로 완성되어 있을 것
4. 사용 가이드, 패키징, 구매 후 메일까지 함께 완성되어 있을 것
5. PDF와 Notion 둘 다 실제 제공 가능한 상태여야 할 것

### 현재 판단
- 코어 15는 기준선 역할을 할 수 있음
- 전체 50개는 아직 완성 상태가 아님
- 따라서 “완전 판매 준비 완료”라고 보기에는 아직 이르다

---

## 6. 운영/발송 출시 기준
아래 항목을 모두 만족해야 합니다.

1. 신청 폼이 실제로 수집 가능할 것
2. 발신 메일 주소가 실제 운영 가능한 상태일 것
3. 샘플팩 링크와 스타터팩 링크가 모두 정상 동작할 것
4. 결제 완료를 확인하는 방식이 정해져 있을 것
5. 실제로 이메일을 보내는 절차가 운영자가 혼동 없이 실행 가능할 것

### 현재 판단
- 기준 문서는 충분히 있음
- 실제 값과 링크 입력은 아직 남아 있음

---

## 7. 출시 가능 판정 단계

### 7.1 내부 준비 단계
- 문서와 자산이 갖춰지는 단계
- 아직 외부 공개 전

### 7.2 테스트 공개 가능 단계
- 샘플팩/무료 결과/운영 흐름이 준비됨
- 소규모 사용자에게 테스트 가능

### 7.3 정식 판매 가능 단계
- 샘플팩 발송 안정화
- 유료 스타터팩 50개 완성
- 결제/발송/안내 흐름 안정화

---

## 8. 현재 AI시킴의 위치
현재 AI시킴은 `내부 준비 단계 후반`에서 `테스트 공개 가능 단계 초입` 사이에 있습니다.

즉:
- 무료 결과: 강해지는 중
- 샘플팩: 거의 테스트 가능한 수준
- 유료 스타터팩: 코어 15는 강하지만 전체 50개는 아직 완성 필요
- 운영 연결: 실제 값 입력 필요

---

## 9. 출시 전에 반드시 끝내야 할 것
1. 샘플팩 PDF 실물 제작
2. 샘플팩 Notion 실물 제작
3. 스타터팩 50개 전체 완성
4. 스타터팩 PDF 실물 제작
5. 스타터팩 Notion 실물 제작
6. 실제 링크 생성
7. 실제 발신 메일 주소 결정
8. 신청/결제/발송 흐름 최종 점검

---

## 10. 최종 기준
AI시킴은 “서비스가 돌아간다”로는 부족합니다.  
사용자가 무료에서 만족하고, 샘플팩에서 신뢰하고, 유료팩에서 돈값 한다고 느껴야 합니다.  
그 전까지는 출시 준비 중 상태로 판단합니다.
