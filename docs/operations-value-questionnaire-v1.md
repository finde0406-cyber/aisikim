# AI시킴 운영값 결정 질문표 v1

## 1. 문서 목적
이 문서는 AI시킴 운영값을 실제로 확정하기 위해, 무엇을 어떤 순서로 결정하면 되는지 질문형으로 정리한 문서입니다.  
이 질문표의 답만 정리되면, 다음 단계에서 Claude Code에게 실제 자동 발송/운영 연결 구현을 맡길 수 있습니다.

## 2. 사용 방법
- 아래 질문에 바로 답합니다.
- 아직 결정 못한 것은 `보류`로 적어도 됩니다.
- 단, `필수` 항목은 구현 전 반드시 결정해야 합니다.
- 답이 정해지면 `operations-decision-checklist-v1.md`에도 같은 값을 반영합니다.

## 6. 지금 가장 먼저 결정해야 하는 최소 6개
아래 6개만 정해도 Claude Code 구현 프롬프트가 명확해집니다.

1. 무료 신청 수집 도구
2. 무료 발신 메일 주소
3. 샘플팩 PDF 링크
4. 샘플팩 Notion 링크
5. 스타터팩 PDF/Notion/가이드 링크
6. 유료 결제 완료 확인 방식

## 7. 가장 현실적인 1차 답안 예시

### 무료
- 신청 수집: Tally
- 데이터 확인: Tally + Google Sheets
- 발신 주소: hello@
- 발송 방식: 반자동
- 제공 형태: PDF + Notion

### 유료
- 결제 방식: 외부 결제 링크
- 결제 완료 확인: 수동 또는 반자동
- 발신 주소: hello@ 또는 support@
- 제공 형태: PDF + Notion + 사용 가이드

## 8. 이 문서를 다 채우면 다음에 할 일
이 질문표가 채워지면 다음 단계는 아래 중 하나입니다.

1. Claude Code에게 실제 운영 연결 구현 프롬프트 전달
2. 링크/메일 주소/폼 도구를 실제 서비스에 반영
3. 자동 발송 또는 반자동 발송 구조 구현

## 9. 최종 기준
운영값은 “나중에 정하면 되겠지”라고 미루면 구현과 운영이 꼬입니다.  
반대로 이 질문표만 먼저 채워두면, 이후 연결 구현은 훨씬 빠르고 정확하게 진행할 수 있습니다.
