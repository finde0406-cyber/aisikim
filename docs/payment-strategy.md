# 결제 전략

## 1. 문서 목적
이 문서는 AI시킴 MVP에서 자체 결제를 제외하고 외부 결제 링크 방식으로 시작하는 이유와 후보 채널 비교, 우선안을 정리합니다.

## 2. 초기 결제 원칙
- 자체 결제 시스템은 1차 MVP에서 제외
- 빠른 검증과 낮은 운영 복잡도를 우선
- 구매자 신뢰와 운영 편의의 균형을 고려
- 결제 후 자료 제공은 PDF + Notion 보조 링크를 기본 가정으로 유지

## 3. 후보 방식 비교
### 3.1 Tally 또는 간단한 신청폼 + 수동 안내/수동 발송
장점
- 1차 MVP에서 가장 빠르게 시작 가능
- 신청 수요와 구매 의사를 먼저 검증하기 좋음
- 운영자가 직접 응대하며 초기 고객 반응을 파악할 수 있음

주의점
- 수동 운영 부담이 큼
- 결제 경험과 자료 전달 흐름이 덜 자동화됨
- 판매량이 늘어나면 빠르게 비효율이 생길 수 있음

### 3.2 스마트스토어
장점
- 국내 사용자 신뢰도가 높음
- 구매자가 익숙한 환경일 가능성이 큼

주의점
- 디지털 자료 판매 운영 방식 확인 필요
- 상품 구성과 전달 방식 정리가 필요

### 3.3 크몽
장점
- 플랫폼 신뢰가 있음
- 서비스형 판매와 설명 구조에 익숙함

주의점
- 플랫폼 수수료 및 운영 정책 고려 필요
- 플랫폼 특성상 일반 상품 페이지와는 다른 운영 감각이 필요

### 3.4 수동 계좌이체 또는 기타 외부 결제 링크
장점
- 운영자가 가장 유연하게 대응 가능
- 초기 소규모 판매 실험에 맞추기 쉬움

주의점
- 사용자 신뢰 확보 장치가 필요함
- 자동화 수준이 낮아 운영 품질 편차가 생길 수 있음

### 3.5 Lemon Squeezy
장점
- 디지털 상품 판매 구조에 적합
- 링크 기반 판매가 쉬움
- 해외 SaaS형 판매 흐름에 익숙함

주의점
- 국내 사용자에게는 다소 낯설 수 있음
- 세금, 정산, 안내 문구를 더 신중히 설명해야 할 수 있음

## 4. 자체 결제 제외 이유
- MVP의 핵심은 결제 기술 구현이 아니라 판매 검증
- 회원, 주문, 영수증, 환불, 보안 처리까지 범위가 커짐
- 빠른 출시와 첫 판매 실험에 불리함

## 5. 결제 후 자료 제공 방식
- 기본 제공: PDF
- 보조 제공: Notion 링크
- 1차 MVP에서는 수동 안내 및 수동 발송을 기본 가정으로 둔다.
- 결제 완료 후 안내 문구와 자료 수령 방식을 명확히 고지한다.

## 6. MVP 우선안 제안
### 우선안 방향
- 특정 하나를 지금 확정하지 않는다.
- 1차 MVP 우선안은 `Tally 또는 간단한 신청폼 + 수동 안내/수동 발송`으로 둔다.
- 실제 결제는 크몽, 스마트스토어, 수동 계좌이체, 기타 외부 결제 링크 중 선택할 수 있게 비교한다.
- Lemon Squeezy는 해외형 디지털 상품 판매에는 적합하지만 국내 사용자 결제 경험 관점에서는 2순위 후보로 둔다.

### 문서 기준 제안
- 신청과 안내는 가장 단순한 방식으로 먼저 검증한다.
- 실제 결제 수단은 국내 사용자 신뢰와 운영 난이도를 기준으로 비교한다.
- 자체 결제 시스템은 MVP에서 제외한다.

## 7. 환불/디지털 상품 안내 문구 초안
- 본 상품은 디지털 자료 상품입니다.
- 결제 후 자료가 전달된 이후에는 상품 특성상 환불 기준이 제한될 수 있습니다.
- 상세 환불 기준은 결제 페이지 또는 상품 안내 페이지에서 명확히 고지합니다.

## 8. 결론
AI시킴 MVP의 결제 전략은 "가장 멋진 시스템"이 아니라 "가장 빨리 검증 가능한 구조"를 선택하는 데 있습니다.  
지금 단계에서는 특정 수단 확정보다 비교와 우선안 제안이 더 적절합니다.
