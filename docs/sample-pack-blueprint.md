# AI시킴 샘플팩 5개 실물 설계

## 1. 문서 목적
이 문서는 AI시킴의 무료 샘플팩 5개를 실제로 제작할 때 따라야 하는 구성 기준과 작성 템플릿을 정의합니다.  
샘플팩은 단순한 무료 자료가 아니라, 사용자가 유료 상품을 신뢰하게 만드는 핵심 경험이므로 품질 기준을 구체적으로 고정합니다.

## 2. 샘플팩 역할
- 무료 결과 1개보다 한 단계 더 깊은 품질을 보여준다.
- 사용자가 "이 서비스는 진짜 더 써볼 만하다"라고 느끼게 한다.
- 스타터팩 구매 전 마지막 신뢰 형성 구간이다.
- AI시킴의 작업지시서 방식이 실제로 어떻게 다른지 짧게 증명한다.

## 3. 샘플팩 구성 원칙
### 3.1 초기 MVP 카테고리와 직접 연결
- 블로그/콘텐츠
- 업무/보고서
- 앱/웹사이트 개발
- 공통 AI 활용/작업설계
- 결과물 검수/수정

### 3.2 서로 다른 상황을 보여줄 것
- 같은 카테고리 안에서도 다른 상황에서 쓸 수 있어야 한다.
- 사용자가 "내 상황과 비슷한 게 있다"라고 느껴야 한다.

### 3.3 바로 복사해 쓸 수 있어야 한다
- 설명만 있고 본문이 약하면 안 된다.
- 샘플팩 안의 각 자료는 바로 복사할 수 있는 작업지시서 본문을 포함해야 한다.

## 4. 샘플팩 5개 권장 구성
1. 블로그 글 초안 만들기
2. 업무 보고서 초안 정리
3. 앱/웹사이트 기능 정의 요청하기
4. 공통 AI 활용/작업설계 시작하기
5. AI 결과물 수정 및 검수 요청하기

## 5. 각 샘플의 필수 구성
각 샘플은 아래 순서를 기본 템플릿으로 사용합니다.

1. 제목
2. 이 작업지시서가 필요한 상황
3. 언제 쓰면 좋은지
4. 바로 복사해서 쓸 본문
5. 바꿔야 할 부분
6. 후속 질문 예시
7. 수정 요청 예시
8. 짧은 활용 팁

## 6. 샘플 개별 템플릿
### 6.1 제목
예:
- 블로그 글 초안을 빠르게 잡고 싶을 때
- 보고서 목차와 본문 구조를 동시에 정리하고 싶을 때

### 6.2 필요한 상황
예:
- 글을 써야 하는데 어디서 시작할지 막막할 때
- 보고서를 써야 하는데 구조를 어떻게 잡아야 할지 모를 때

### 6.3 언제 쓰면 좋은지
예:
- 처음 질문을 던질 때
- AI 답변을 조금 더 구체적으로 만들고 싶을 때

### 6.4 바로 복사해서 쓸 본문
예시 형식:
```text
지금 저는 [상황]을 하고 있습니다.
[결과물]이 필요합니다.

먼저 제가 놓치고 있는 핵심 요소가 있다면 질문해 주세요.
그 다음 [원하는 형식]으로 결과를 만들어 주세요.

답변은 [스타일]로 작성해 주세요.
가능하면 바로 활용할 수 있는 형태로 정리해 주세요.
```

### 6.5 바꿔야 할 부분
예:
- `[상황]`에 내 현재 작업을 넣기
- `[결과물]`에 글 초안 / 보고서 / 기능 정의 등 넣기
- `[스타일]`에 친절하게 / 전문가처럼 / 실행 중심으로 등 넣기

### 6.6 후속 질문 예시
예:
- 위 초안을 더 구체적으로 다듬기 위해, 대상 독자 기준으로 다시 써줘.
- 지금 구조를 유지한 채 더 짧고 명확하게 바꿔줘.

### 6.7 수정 요청 예시
예:
- 너무 일반적인 표현은 줄이고 실제로 바로 쓸 수 있는 문장으로 바꿔줘.
- 항목을 더 실무적으로 다시 나눠줘.

### 6.8 활용 팁
예:
- 첫 답변이 마음에 들지 않으면 후속 질문과 수정 요청을 바로 이어서 사용하세요.
- 처음부터 완벽한 답을 기대하기보다, 흐름을 이어가며 완성도를 높이는 방식이 더 좋습니다.

## 7. 샘플팩 디자인/전달 기준
### 7.1 PDF 기준
- 한 샘플당 1페이지 또는 1~2페이지 이내
- 제목과 본문이 바로 보이게 구성
- 복사할 본문 영역은 시각적으로 구분

### 7.2 Notion 기준
- 샘플별 토글 또는 구분 섹션
- 복사 버튼 위치를 고려한 간결한 배치
- "언제 쓰는지 / 바로 복사 / 후속 질문 / 수정 요청" 순서 유지

## 8. 샘플팩 완성 체크리스트
- 샘플 5개가 서로 다른 상황을 보여주는가
- 각 샘플에 바로 복사할 본문이 포함되어 있는가
- 사용자가 바꿔야 할 부분이 명확한가
- 후속 질문과 수정 요청이 포함되어 있는가
- 무료 결과보다 확실히 좋다는 느낌이 드는가
- 유료팩에 대한 기대가 생기는가

## 9. 최종 기준
샘플팩은 "무료라서 적당히 준 자료"가 아니라, 유료 스타터팩을 믿고 살 수 있게 만드는 품질 증명 자료여야 합니다.  
사용자가 샘플팩 1~2개만 써봐도 "이건 진짜 더 써볼 만하다"라고 느껴야 합니다.
