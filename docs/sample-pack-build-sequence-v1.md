# AI시킴 샘플팩 실물 제작 순서 v1

## 1. 문서 목적
이 문서는 AI시킴 샘플팩을 실제로 발송 가능한 `PDF + Notion` 자산으로 만들기 위해, 어떤 순서로 작업하면 되는지 정리한 실무용 제작 문서입니다.  
지금 단계의 목표는 새로운 내용을 더 만드는 것이 아니라, 이미 만든 샘플팩 초안과 패키징 문서를 바탕으로 실제 링크를 만들 수 있는 상태까지 정리하는 것입니다.

## 3. 최종 산출물
샘플팩 실물 제작이 끝나면 아래 3개가 있어야 합니다.

1. 샘플팩 PDF 최종본
2. 샘플팩 Notion 공개 링크
3. 샘플팩 발송 메일에 넣을 실제 링크

## 4. 권장 제작 순서

### 1단계: 최종 본문 확정
해야 할 일:
- `sample-pack-ready-v1.md`를 기준으로 샘플 5개 본문을 마지막으로 한 번 더 검토
- 지나치게 중복되는 표현이 없는지 확인
- 실제 복붙이 자연스러운지 확인

완료 기준:
- 샘플 5개 본문이 더 이상 큰 수정 없이 써도 되는 수준

### 2단계: PDF용 구조 정리
해야 할 일:
- 표지 문안 확정
- 사용법 1페이지 문안 확정
- 추천 시작 경로 페이지 문안 확정
- 샘플 5개 순서 확정
- 마지막 스타터팩 안내 문안 확정

완료 기준:
- PDF로 옮길 페이지 구조가 정해짐

### 3단계: Notion용 구조 정리
해야 할 일:
- 상단 안내 블록 작성
- 샘플 5개를 카드/토글형으로 배치
- 복사 본문이 가장 먼저 눈에 띄게 배치
- 하단 스타터팩 안내 블록 추가

완료 기준:
- Notion에 바로 옮겨 적을 구조가 정해짐

### 4단계: 실제 자산 생성
해야 할 일:
- PDF 파일 생성
- Notion 페이지 작성
- 공유 링크 생성

완료 기준:
- PDF 링크 1개
- Notion 링크 1개

### 5단계: 링크 검수
해야 할 일:
- 링크가 로그인 없이 열리는지 확인
- 모바일에서 열리는지 확인
- PDF와 Notion이 같은 내용 톤을 유지하는지 확인

완료 기준:
- 실제 발송 메일에 넣을 수 있는 링크 상태

## 5. PDF 페이지 추천 구조

### 페이지 1
- 표지

### 페이지 2
- 이 자료는 무엇인지
- 어떻게 쓰면 좋은지

### 페이지 3
- 추천 시작 경로

### 페이지 4~8
- 샘플 1~5

### 페이지 9
- 다음 단계 안내

## 6. Notion 추천 구조

### 상단
- 샘플팩 소개
- 무엇부터 써야 하는지

### 중간
- 샘플 1~5
  - 제목
  - 한 줄 설명
  - 복사 본문
  - 바꿔야 할 부분
  - 후속 질문
  - 수정 요청
  - 검수 요청

### 하단
- 스타터팩 안내
- 문의 안내

## 7. 실무적으로 먼저 해야 하는 것
가장 먼저 추천하는 순서:

1. 샘플팩 PDF에 들어갈 표지/사용법/마지막 안내 문구 먼저 확정
2. Notion 구조 복붙용 블록 확정
3. 그 다음 실제 파일 생성

이유:
- 디자인보다 문안이 먼저 고정돼야
- PDF와 Notion의 내용 불일치가 줄어듭니다.

## 8. Claude Code가 필요한 시점
샘플팩 실물 제작은 대부분 문서/콘텐츠 작업이라 지금 당장은 Claude Code가 꼭 필요하지 않습니다.  
Claude Code가 필요한 시점은 아래와 같습니다.

1. 실제 샘플팩 링크를 서비스 결과 페이지와 메일 흐름에 반영할 때
2. 폼 제출 후 실제 링크가 자동 또는 반자동으로 발송되게 연결할 때

즉, 샘플팩 PDF와 Notion 링크가 실제로 생긴 뒤에 투입하는 것이 효율적입니다.

## 9. 최종 기준
샘플팩은 “일단 보내는 자료”가 아니라, 사용자가 AI시킴을 믿게 만드는 첫 실물 자산입니다.  
따라서 샘플 5개 본문만 중요한 것이 아니라, 무엇부터 써야 하는지와 다음 단계가 무엇인지까지 함께 정리된 상태여야 합니다.
