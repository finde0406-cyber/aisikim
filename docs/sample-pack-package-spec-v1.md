# AI시킴 샘플팩 패키징 설계 v1

## 1. 문서 목적
이 문서는 무료 샘플팩 5개를 실제 사용자에게 전달할 때, 어떤 순서와 구성으로 보여줘야 가장 이해하기 쉽고 체감 가치가 높아지는지를 정리한 패키징 설계 문서입니다.  
샘플팩은 단순한 무료 자료가 아니라, 사용자가 AI시킴의 방식을 실제로 체험하고 신뢰를 형성하는 첫 운영 자산이라는 전제로 설계합니다.

## 2. 샘플팩의 역할 재정의
샘플팩은 단순히 “무료로 5개 더 준다”가 아닙니다.

샘플팩이 해야 하는 일:
1. 무료 결과 1개보다 더 깊은 체감을 준다
2. 사용자가 “이 서비스는 더 써볼 만하다”라고 느끼게 한다
3. 스타터팩으로 이어질 신뢰를 만든다
4. 이메일을 남긴 것이 아깝지 않다고 느끼게 한다

## 3. 전달물 구성 원칙
샘플팩은 아래 3개 묶음으로 전달하는 것을 기본 기준으로 합니다.

### 3.1 발송 메일
- 무엇을 받았는지
- 무엇부터 써야 하는지
- PDF / Notion 중 어디를 먼저 보면 좋은지
- 다음 단계가 무엇인지

### 3.2 PDF
- 보관용
- 인쇄/공유 가능
- 처음 받았을 때 “정리되어 있다”는 인상을 주는 역할

### 3.3 Notion 보조 링크
- 복사하기 쉬움
- 빠르게 탐색하기 쉬움
- 모바일에서 바로 쓰기 쉬움

## 4. 샘플팩 PDF 권장 페이지 흐름

### 4.1 표지
- 제목: `AI시킴 무료 작업지시서 샘플팩`
- 부제: `지금 막힌 작업부터 바로 써볼 수 있는 실전 작업지시서 5개`
- 짧은 안내: `처음부터 전부 읽기보다, 지금 가장 필요한 샘플 1개부터 써보세요.`

### 4.2 1페이지: 사용법
- 이 자료는 무엇인지
- 어떻게 쓰면 좋은지
- 대괄호 `[]` 안은 바꿔야 한다는 점
- 첫 답변이 약하면 후속 질문 / 수정 요청 / 검수 요청까지 이어서 써야 한다는 점

### 4.3 2페이지: 추천 시작 경로
- 글이 막히는 사람 → 샘플 1
- 보고서가 막히는 사람 → 샘플 2
- 기능 정의가 막히는 사람 → 샘플 3
- AI를 어떤 순서로 써야 할지 모르겠는 사람 → 샘플 4
- 이미 나온 결과가 아쉬운 사람 → 샘플 5

### 4.4 3페이지~7페이지: 샘플 5개
각 샘플은 아래 순서를 유지합니다.
1. 제목
2. 이런 상황에서 쓰세요
3. 기대할 수 있는 결과
4. 바로 복사할 본문
5. 바꿔야 할 부분
6. 후속 질문
7. 수정 요청
8. 검수 요청
9. 사용 팁

### 4.5 마지막 페이지: 다음 단계 안내
- 샘플팩은 시작용 자료라는 점
- 더 완성된 흐름이 필요하면 스타터팩에서 후속 질문, 수정 요청, 검수 요청까지 더 넓게 확인할 수 있다는 점
- 스타터팩 안내 링크

## 5. 샘플팩 Notion 권장 구조

### 상단 안내 블록
- 무엇부터 써야 하는지
- 복사 전 무엇을 바꿔야 하는지
- 첫 답변이 약할 때 어떻게 이어갈지

### 빠른 시작 섹션
- `지금 가장 필요한 샘플 1개부터 시작하세요`
- 각 샘플을 카드 또는 토글로 구분

### 샘플별 구조
- 제목
- 한 줄 설명
- 복사 본문
- 바꿔야 할 부분
- 후속 질문
- 수정 요청
- 검수 요청

### 하단 안내
- 스타터팩 보기
- 자주 묻는 질문 2~3개

## 6. 사용자 입장에서 좋은 샘플팩의 조건
- 읽자마자 무엇을 받았는지 이해된다
- 어디부터 써야 하는지 고민이 없다
- 복사할 본문이 눈에 잘 들어온다
- 무료인데도 허술하지 않다
- “이 정도면 유료도 궁금하다”는 느낌이 든다

## 7. 샘플팩에서 반드시 피해야 할 것
- 사용법 설명 없이 본문만 나열된 PDF
- 복사할 본문이 눈에 안 띄는 구성
- “무료라서 대충 준 자료”처럼 보이는 밀도
- 스타터팩 광고만 길고, 샘플 자체는 약한 구조

## 8. 배포 전 점검 질문
- 첫 페이지 30초 안에 무엇을 받았는지 이해되는가
- 사용자가 어떤 샘플부터 써야 할지 바로 알 수 있는가
- 모바일에서도 복사 흐름이 불편하지 않은가
- 샘플 1개만 써봐도 AI시킴의 방식이 전달되는가

## 9. 최종 기준
샘플팩은 무료 자료이지만, 사용자 입장에서는 “이 서비스가 진짜 쓸 만한지 처음 확인하는 기준”입니다.  
따라서 내용 품질뿐 아니라, 전달 순서와 포맷까지도 신뢰를 주는 구조여야 합니다.
