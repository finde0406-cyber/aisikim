# AI시킴 스타터팩 구매 후 안내 메일 초안 v1

## 1. 문서 목적
이 문서는 유료 스타터팩 구매자에게 실제로 보낼 구매 후 안내 메일 초안입니다.  
구매 직후 사용자가 “자료는 받았는데 뭐부터 봐야 하지?” 상태에 빠지지 않게 하고, 첫 사용 경험을 부드럽게 만드는 것이 목적입니다.

## 2. 제목 초안
### 제목안 1
[AI시킴] 스타터팩 자료를 보내드립니다

### 제목안 2
[AI시킴] 구매하신 작업지시서 스타터팩 50개 안내

### 제목안 3
[AI시킴] 지금 바로 써볼 수 있는 스타터팩 자료를 준비했습니다

## 3. 메일 본문 초안
안녕하세요. AI시킴입니다.

구매해주셔서 감사합니다.  
이번 메일에는 구매하신 `AI 작업지시서 스타터팩` 자료와 함께, 무엇부터 보면 좋은지 바로 시작할 수 있는 안내를 담았습니다.

### 이번 메일에 포함된 자료
- 스타터팩 PDF: [여기에 PDF 링크 삽입]
- Notion 보조 링크: [여기에 Notion 링크 삽입]
- 사용 가이드: [여기에 사용 가이드 링크 삽입]

### 먼저 이렇게 시작해보세요
처음부터 50개를 전부 보실 필요는 없습니다.  
지금 가장 막힌 작업과 가까운 카테고리 1개만 먼저 고르시는 것을 추천드립니다.

- 블로그 글이나 콘텐츠가 급하다면 → 블로그/콘텐츠
- 보고서나 업무 문서가 급하다면 → 업무/보고서
- 기능 정의나 개발 요청이 급하다면 → 앱/웹사이트 개발
- 이미 나온 결과를 더 좋게 다듬고 싶다면 → 결과물 검수/수정
- 무엇부터 해야 할지 전혀 모르겠다면 → 공통 AI 활용/작업설계

### 가장 추천하는 사용 순서
1. 관련 카테고리에서 초안 생성형 작업지시서 1개를 고릅니다.
2. 첫 답변이 나오면 후속 질문 예시를 이어서 사용합니다.
3. 결과가 마음에 들지 않으면 수정 요청 예시를 사용합니다.
4. 마지막으로 검수 요청 예시로 점검합니다.

즉, 한 번 던지고 끝내는 자료가 아니라 `처음 요청 → 발전 → 수정 → 최종 점검`까지 이어지는 자료라고 생각해주시면 좋습니다.

### 사용 전에 꼭 기억할 점
- 대괄호 `[]` 안의 내용은 내 상황에 맞게 꼭 바꿔야 합니다.
- 첫 답변이 약해도 바로 포기하지 말고 후속 질문과 수정 요청까지 이어가면 결과가 훨씬 좋아집니다.
- 처음부터 전부 쓰려 하기보다, 지금 가장 필요한 1개부터 시작하는 것이 좋습니다.

### 문의가 필요하시면
자료를 보시다가 어떤 항목부터 써야 할지 애매하거나, 활용 방식이 헷갈리면 이 메일에 답장해 주세요.

감사합니다.
