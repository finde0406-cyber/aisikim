# AI시킴 스타터팩 개별 항목 검수 체크리스트 v1

## 1. 문서 목적
이 문서는 스타터팩 안의 각 작업지시서가 실제 유료 상품 수준에 도달했는지 검수하기 위한 체크리스트입니다.  
작업지시서 개수가 많아질수록 품질 편차가 생기기 쉬우므로, 출고 전 최소 기준을 동일하게 적용하기 위한 용도로 사용합니다.

---

## 2. 사용 방법
각 작업지시서를 검토할 때 아래 항목을 하나씩 확인합니다.

- `통과`: 유료 상품 기준에 부합
- `보완 필요`: 문장이나 구조 보완 후 다시 검토
- `재작성 필요`: 역할이 약하거나 중복되어 본문을 다시 써야 함

가능하면 각 항목마다 짧은 검토 메모를 함께 남깁니다.

---

## 3. 기본 구조 체크
아래 요소가 모두 들어 있는지 확인합니다.

1. 목적
2. 언제 쓰는지
3. 바로 복사할 본문
4. 바꿔야 할 부분
5. 후속 질문 예시
6. 수정 요청 예시
7. 검수 요청 예시
8. 사용 팁

### 판정
- 8개 모두 있음: 통과
- 1~2개 부족: 보완 필요
- 3개 이상 부족: 재작성 필요

---

## 4. 실전성 체크
아래를 확인합니다.

1. 사용자가 바로 복사해 쓸 수 있는가
2. 너무 추상적이지 않은가
3. 실제 상황에서 자주 막히는 문제를 다루고 있는가
4. 단순 조언이 아니라 바로 실행 가능한 문장인가

### 판정
- 4개 모두 만족: 통과
- 1개 약함: 보완 필요
- 2개 이상 약함: 재작성 필요

---

## 5. 차별성 체크
아래를 확인합니다.

1. 샘플팩보다 확실히 깊은가
2. 다른 작업지시서와 역할이 겹치지 않는가
3. 이 항목만의 분명한 사용 시점이 있는가

### 판정
- 3개 모두 만족: 통과
- 1개 애매함: 보완 필요
- 2개 이상 애매함: 재작성 필요

---

## 6. 후속 흐름 체크
아래를 확인합니다.

1. 후속 질문이 실제로 결과를 더 좋게 만드는가
2. 수정 요청이 단순 반복이 아니라 보완 방향을 주는가
3. 검수 요청이 마지막 품질 점검 역할을 하는가

### 판정
- 3개 모두 만족: 통과
- 1개 약함: 보완 필요
- 2개 이상 약함: 재작성 필요

---

## 7. 톤/이해도 체크
아래를 확인합니다.

1. 초보자도 이해 가능한가
2. 너무 유치하거나 장난스럽지 않은가
3. 실무자도 돈값 한다고 느낄 만한 밀도가 있는가

### 판정
- 3개 모두 만족: 통과
- 1개 약함: 보완 필요
- 2개 이상 약함: 재작성 필요

---

## 8. 최종 출고 판정

### 출고 가능
- 기본 구조 통과
- 실전성 통과
- 차별성 통과
- 후속 흐름 통과
- 톤/이해도 통과

### 조건부 출고
- 대부분 통과했지만 1~2개 항목만 보완 필요

### 출고 보류
- 재작성 필요 항목이 하나라도 있음

---

## 9. 검토 메모 템플릿
검토 시 아래 형식으로 메모를 남길 수 있습니다.

```text
항목명:
기본 구조: 통과 / 보완 필요 / 재작성 필요
실전성: 통과 / 보완 필요 / 재작성 필요
차별성: 통과 / 보완 필요 / 재작성 필요
후속 흐름: 통과 / 보완 필요 / 재작성 필요
톤/이해도: 통과 / 보완 필요 / 재작성 필요
총평:
다음 조치:
```

---

## 10. 최종 원칙
스타터팩의 개별 항목은 “문장이 들어 있다”로 끝나면 안 됩니다.  
사용자가 실제로 반복해서 꺼내 쓰고, 결과 품질 차이를 체감하고, 돈값 한다고 느껴야 합니다.  
이 체크리스트는 그 기준을 지키기 위한 최소 안전장치입니다.
