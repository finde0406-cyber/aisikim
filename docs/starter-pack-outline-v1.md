# AI시킴 스타터팩 50개 목차/분배표 v1

## 1. 문서 목적
이 문서는 `AI 작업지시서 스타터팩` 50개를 실제로 제작할 때 사용할 목차 초안과 분배 구조를 정의합니다.  
각 카테고리별로 어떤 작업지시서를 넣을지 미리 설계해, 콘텐츠 제작 시 중복을 줄이고 전체 품질을 일정하게 유지하기 위한 문서입니다.

## 2. 스타터팩 전체 구조
스타터팩은 아래 5개 카테고리로 구성합니다.

1. 블로그/콘텐츠 작업지시서 10개
2. 업무/보고서 작업지시서 10개
3. 앱/웹사이트 개발 작업지시서 10개
4. 결과물 검수/수정 작업지시서 10개
5. 공통 AI 활용/작업설계 작업지시서 10개

총 50개 작업지시서

## 3. 구성 원칙
- 각 카테고리 안에 `초안 생성`, `구체화`, `수정`, `검수` 흐름이 고르게 섞여 있어야 한다.
- 사용자가 "이 카테고리에서 실제로 자주 막히는 상황"을 우선 반영한다.
- 제목만 다른 유사 작업지시서가 여러 개 들어가면 안 된다.
- 샘플팩 5개와 겹치더라도, 유료판에서는 더 깊고 실전적인 버전으로 제공해야 한다.

## 4. 카테고리별 목차 초안

### 4.1 블로그/콘텐츠 작업지시서 10개
1. 블로그 글의 첫 구조를 잡고 싶을 때
2. 글 제목 후보를 여러 방향으로 뽑고 싶을 때
3. 도입부를 더 강하게 쓰고 싶을 때
4. 소제목 구조를 더 읽기 좋게 정리하고 싶을 때
5. 정보형 글을 더 구체적으로 확장하고 싶을 때
6. 판매형 콘텐츠 문구를 자연스럽게 녹이고 싶을 때
7. 같은 내용을 짧은 SNS용 문구로 바꾸고 싶을 때
8. 글 초안을 대상 독자에 맞게 다시 다듬고 싶을 때
9. 블로그 글의 마무리와 CTA를 더 좋게 쓰고 싶을 때
10. 완성된 글을 전체 검수하고 수정하고 싶을 때

### 4.2 업무/보고서 작업지시서 10개
1. 업무 보고서의 기본 구조를 잡고 싶을 때
2. 보고서 목차를 더 설득력 있게 만들고 싶을 때
3. 회의록을 실무 문서로 정리하고 싶을 때
4. 상사 보고용 요약본을 짧게 만들고 싶을 때
5. 기획서 초안을 항목별로 채우고 싶을 때
6. 업무 이메일을 더 명확하게 쓰고 싶을 때
7. 실행 계획을 체크리스트로 정리하고 싶을 때
8. 문제 보고 문서를 더 차분하고 정확하게 쓰고 싶을 때
9. 제안서를 읽는 사람이 바로 이해하게 고치고 싶을 때
10. 완성된 보고서나 기획서를 최종 검수하고 싶을 때

### 4.3 앱/웹사이트 개발 작업지시서 10개
1. 기능 요구사항을 처음 정리하고 싶을 때
2. 사용자 흐름을 화면 단위로 정리하고 싶을 때
3. 개발자에게 전달할 작업 지시문을 만들고 싶을 때
4. 버그 상황을 더 정확하게 설명하고 싶을 때
5. UI 수정 요청을 더 구체적으로 하고 싶을 때
6. API 연동 작업을 설명하고 싶을 때
7. MVP 범위와 추후 확장 범위를 나누고 싶을 때
8. 코드를 직접 짜기 전 구조 제안을 받고 싶을 때
9. 이미 나온 코드나 구현안을 개선 요청하고 싶을 때
10. 개발 결과물을 최종 검수하고 싶을 때

### 4.4 결과물 검수/수정 작업지시서 10개
1. 너무 일반적인 답변을 더 구체적으로 바꾸고 싶을 때
2. 길기만 한 결과물을 더 짧고 명확하게 만들고 싶을 때
3. 방향은 맞지만 완성도가 낮은 결과를 다듬고 싶을 때
4. 독자나 대상에 맞게 톤을 바꾸고 싶을 때
5. 빠진 핵심 요소가 있는지 점검하고 싶을 때
6. 추상적인 표현을 실제 예시 중심으로 바꾸고 싶을 때
7. 읽기 쉬운 구조로 다시 나누고 싶을 때
8. 더 설득력 있게 다시 쓰고 싶을 때
9. 최종 제출 전 품질 체크를 받고 싶을 때
10. 여러 수정 버전 중 더 나은 방향을 판단하고 싶을 때

### 4.5 공통 AI 활용/작업설계 작업지시서 10개
1. AI 작업을 어떤 순서로 시작해야 할지 모르겠을 때
2. 첫 질문을 더 잘 시작하고 싶을 때
3. 내 상황을 AI에게 설명하는 문장을 만들고 싶을 때
4. 원하는 결과물 형식을 먼저 고정하고 싶을 때
5. 후속 질문 흐름을 설계하고 싶을 때
6. 수정 요청을 어떻게 이어갈지 설계하고 싶을 때
7. 검수 질문을 어떻게 던질지 정리하고 싶을 때
8. 같은 작업을 다른 AI 도구에 맞게 바꾸고 싶을 때
9. AI 답변이 뻔할 때 더 깊은 답을 끌어내고 싶을 때
10. 전체 작업 흐름을 한 번에 설계하고 싶을 때

## 7. 스타터팩 제작 체크리스트
- 50개가 실제로 서로 다른 상황을 다루는가
- 카테고리별 성격 차이가 분명한가
- 각 작업지시서에 템플릿 8요소가 들어가는가
- 샘플팩보다 깊고 강한가
- 초보자도 이해할 수 있지만, 실사용자도 만족할 수 있는가
- 유료라는 기대치에 맞는 설명과 가이드가 포함되는가

## 8. 최종 기준
스타터팩은 "대충 많이 담은 상품"이 아니라, 사용자가 실제 결과물을 완성하기 위해 반복적으로 꺼내 쓸 수 있는 실전용 디지털 상품이어야 합니다.  
이 목차는 그 품질을 일정하게 유지하기 위한 첫 설계 문서입니다.
