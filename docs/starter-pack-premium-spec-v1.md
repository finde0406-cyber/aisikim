# AI시킴 스타터팩 프리미엄 구성 기준 v1

## 1. 문서 목적
이 문서는 유료 `AI 작업지시서 스타터팩`을 실제로 돈 받고 판매해도 되는 수준으로 다듬기 위한 최종 구성 기준 문서입니다.  
단순히 작업지시서 50개를 많이 주는 상품이 아니라, 사용자가 `받자마자 어떻게 쓰고`, `어디를 바꾸고`, `결과가 약하면 어떻게 이어갈지`까지 이해하는 실행형 상품으로 만들기 위한 내부 기준으로 사용합니다.

## 2. 스타터팩이 반드시 줘야 하는 체감
스타터팩을 구매한 사용자는 아래 4가지를 분명히 느껴야 합니다.

1. 무료 결과보다 훨씬 구체적이다
2. 한 번 던지는 문장이 아니라 작업 흐름이 보인다
3. 내가 어디를 바꿔야 하는지 친절하게 안내해준다
4. 그냥 자료를 받은 게 아니라, 실제로 써먹을 수 있는 도구를 산 느낌이 든다

추가로 아래 3가지도 분명해야 합니다.

5. 지금 내 문제와 맞는 항목을 바로 찾을 수 있다
6. 한 번 써보고 끝나는 자료가 아니라, 다음 작업에도 다시 꺼내 쓸 수 있다
7. 무료 작업지시서보다 `왜 돈을 내는지`가 문장을 읽는 순간 느껴진다

## 3. 최종 전달물 구성
스타터팩은 아래 4개 묶음으로 제공하는 것을 기준으로 합니다.

### 3.1 메인 PDF
- 표지
- 이 상품이 필요한 사람
- 가장 먼저 읽어야 할 사용법 2~3페이지
- 카테고리별 작업지시서 50개 본문
- 마지막 페이지의 다음 활용 안내

### 3.2 Notion 보조 링크
- 카테고리별 빠른 탐색
- 복사하기 쉬운 구조
- 업데이트 시 교체가 쉬운 구조

### 3.3 사용 가이드
- 어디부터 써야 하는지
- 어떤 순서로 쓰면 좋은지
- 답변이 약할 때 어떻게 다시 요청하는지

### 3.4 구매 후 안내 메일
- 자료 구성 설명
- 가장 먼저 써볼 추천 작업지시서
- 복사 후 어디를 바꿔야 하는지 안내
- 문의/안내 채널

## 4. 각 작업지시서의 프리미엄 기준
기존 8개 요소는 유지하되, 최종 판매용에서는 아래 요소를 더 강화합니다.

### 4.1 필수 요소
1. 제목
2. 목적
3. 언제 쓰는지
4. 바로 복사할 본문
5. 바꿔야 할 부분
6. 후속 질문 예시
7. 수정 요청 예시
8. 검수 요청 예시

### 4.2 추가로 강화할 요소
9. 기대할 수 있는 결과
10. 이 작업지시서가 특히 잘 맞는 상황
11. 자주 하는 실수 또는 주의할 점
12. 어떤 순서에서 쓰면 좋은지
13. 결과물이 약할 때 어떤 후속 질문부터 써야 하는지
14. 독자/상사/개발자/고객 등 상대에 따라 어떻게 바꾸면 좋은지

### 4.3 유료 작업지시서에서 특히 더 선명해야 하는 것
무료 작업지시서가 `시작`을 돕는다면, 유료 작업지시서는 아래를 분명히 제공해야 합니다.

1. 시작한 뒤 어디로 이어가야 하는지
2. 결과가 약할 때 어떤 식으로 고쳐야 하는지
3. 제출/공유/게시 직전 어떤 질문으로 검수해야 하는지
4. 같은 문제를 다음에도 더 빨리 해결할 수 있는 재사용성

즉 유료는 문장이 더 많아서가 아니라, `흐름`, `판단 기준`, `재사용성`에서 차이가 나야 합니다.

## 5. 고객이 보기 쉬운 페이지 구조
각 작업지시서는 아래처럼 보이는 구성이 좋습니다.

1. 제목
2. 한 줄 설명
3. 이런 상황에서 쓰세요
4. 이 작업지시서로 기대할 수 있는 결과
5. 바로 복사할 본문
6. 바꿔야 할 부분
7. 후속 질문
8. 수정 요청
9. 검수 요청
10. 사용 팁

## 6. 유료팩 설명서에 꼭 들어갈 항목

### 6.1 가장 먼저 써볼 추천 경로
- 블로그/콘텐츠가 급한 사람
- 업무/보고서가 급한 사람
- 개발/기능 정의가 급한 사람
- 결과 수정/검수가 필요한 사람
- 아직 무엇부터 해야 할지 모르는 사람

### 6.2 작업지시서 조합 사용법
- 첫 질문용 1개
- 후속 질문용 1개
- 수정 요청용 1개
- 검수용 1개

즉, 1개의 작업지시서만 던지는 방식이 아니라 서로 조합해서 써야 더 강하다는 점을 설명해야 합니다.

### 6.3 답변이 약할 때의 재시도 규칙
- 더 구체적으로
- 예시 중심으로
- 내 상황 기준으로
- 제출 가능한 수준으로
- 빠진 요소를 먼저 짚고 다시 작성

### 6.4 무료와 유료 차이가 고객에게 바로 보여야 하는 포인트
- 무료: 시작 질문 1개, 첫 방향 잡기, 빠른 체감
- 유료: 후속 질문, 수정 요청, 검수 질문까지 이어지는 완성 흐름
- 무료: “이렇게 물어보면 되겠구나”
- 유료: “이제 결과물을 끝까지 완성할 수 있겠다”

## 7. 프리미엄 상품처럼 보이게 만드는 요소

### 7.1 있어야 하는 것
- 깔끔한 표지
- 첫 사용 순서 안내
- 카테고리 인덱스
- 각 작업지시서의 명확한 역할 구분
- 복사 후 바꿔야 할 부분 표시
- 문의/안내 문구

### 7.2 없어야 하는 것
- 문장만 길게 나열된 PDF
- 사용법 설명이 거의 없는 자료
- 같은 표현이 반복되는 작업지시서
- 무료와 체감 차이가 약한 내용
- 어느 상황에서 꺼내 써야 하는지 감이 안 오는 항목
- 후속 질문과 수정 요청이 형식적으로만 붙은 항목

## 8. 판매 전 최종 점검 질문
- 이 자료를 처음 받는 사람이 5분 안에 이해할 수 있는가
- 사용자가 “어디부터 써야 하지?”에서 막히지 않는가
- 무료 결과보다 확실히 다르다는 느낌이 드는가
- 후속 질문과 수정 요청까지 포함되어 실제 결과 품질을 높일 수 있는가
- 9,900원을 내고 받아도 “사기당했다”는 느낌보다 “생각보다 제대로 만들었네”가 드는가
- 첫 5분 안에 “이건 다음에도 다시 쓰겠다”는 생각이 드는가

## 9. 다음 제작 우선순위
1. 우선 제작 15개 고급화
2. 샘플팩과 톤 맞추기
3. 사용자 가이드 다듬기
4. PDF/Notion 목차 구성
5. 구매 후 메일 최종본 작성

## 10. 최종 기준
스타터팩은 작업지시서 50개를 많이 넣은 상품이 아니라,  
사용자가 실제 결과물을 더 잘 만들도록 돕는 `실행형 디지털 상품`이어야 합니다.  
좋은 문장보다 더 중요한 것은, 사용자가 `그 문장을 언제 어떤 순서로 써야 하는지`까지 이해하는 경험입니다.
