# AI시킴 사용자 흐름

## 1. 전체 흐름
1. 홈 방문
2. 핵심 메시지 확인
3. 진단 시작 CTA 클릭
4. 선택형 질문 진행
5. 무료 결과 확인
6. 이메일 입력 CTA 확인
7. 샘플팩 수령 또는 유료 상품 페이지 이동
8. 외부 결제 링크 이동
9. 구매 후 자료 수령

## 2. 무료 결과 흐름
1. 사용자가 질문에 답한다.
2. 선택 조합에 맞는 기본 작업지시서 1개를 확인한다.
3. "바로 써볼 수 있다"는 체감을 얻는다.
4. 동시에 "이것만으로는 부족할 수 있다"는 인식이 생긴다.
5. 샘플팩 또는 유료 스타터팩으로 이어진다.

## 3. 이메일 수집 흐름
1. 결과 페이지에서 샘플팩 CTA 노출
2. 이메일 입력
3. 동의 문구 확인
4. 제출 완료
5. 샘플팩 발송 안내
6. 이후 교육 메일과 유료 상품 안내 메일 수신

## 4. 유료 결제 흐름
1. 사용자가 유료 스타터팩 소개 섹션 확인
2. 무료 결과와 유료 구성의 차이 이해
3. 외부 결제 링크 클릭
4. 외부 결제 페이지에서 결제
5. 결제 완료 후 PDF + Notion 보조 링크 수령

## 5. 이탈 방지 포인트
- 랜딩 첫 화면에서 문제와 해결 방식을 한 문장으로 보여준다.
- 질문 수를 과도하게 늘리지 않는다.
- 결과 페이지에서 무료 가치와 유료 가치의 차이를 구체적으로 보여준다.
- 이메일 입력 전 "왜 이메일이 필요한지"를 명확히 말한다.
- 외부 결제 전 자료 형식과 수령 방식을 먼저 알려 불안을 낮춘다.

## 6. 사용자 심리 흐름
- 시작 전: "AI는 쓰고 싶은데 뭘 어떻게 물어봐야 할지 모르겠다"
- 질문 중: "직접 쓰지 않아도 되니 편하다"
- 결과 확인 시: "이 정도면 바로 써볼 수 있겠다"
- 샘플팩 CTA 시: "좀 더 받아보고 판단해보자"
- 유료 제안 시: "결과물을 제대로 만들려면 전체 흐름형 자료가 필요하겠다"

## 7. 핵심 전환 지점
- 랜딩에서 진단 시작
- 결과에서 이메일 입력
- 샘플팩 이후 유료 페이지 재방문
- 유료 페이지에서 외부 결제 링크 클릭
