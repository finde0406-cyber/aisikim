# AI시킴 업무/보고서 집중팩 제작 기준 v1

## 1. 문서 목적
이 문서는 `업무/보고서 집중팩`을 실제 고객 판매용으로 제작할 때 필요한 기준을 정리한 문서입니다.

---

## 2. 왜 업무/보고서 집중팩이 중요하나
- 직장인 수요와 직접 연결된다.
- 상사 보고, 기획서, 실행안, 회의록은 반복 사용 가능성이 높다.
- “시간 절약”과 “보고 퀄리티 개선”이라는 구매 이유가 명확하다.

---

## 3. 이 집중팩의 핵심 약속
이 상품은 보고서 문장을 몇 개 주는 것이 아니라,
`실무 문서를 더 빨리, 더 단정하게, 더 판단 가능하게 정리하도록 돕는 패키지`
여야 한다.

고객이 느껴야 하는 핵심은 아래다.
- 보고 초안이 훨씬 빨라진다
- 상사가 읽기 쉬운 구조로 정리된다
- 요약, 실행안, 문제 보고까지 실제 실무 흐름으로 이어진다

---

## 4. 권장 본문 구성

### 4.1 핵심 10개
1. 업무 보고서의 기본 구조를 잡고 싶을 때
2. 보고서 목차를 더 설득력 있게 만들고 싶을 때
3. 회의록을 실무 문서로 정리하고 싶을 때
4. 상사 보고용 요약본을 짧게 만들고 싶을 때
5. 기획서 초안을 항목별로 채우고 싶을 때
6. 업무 이메일을 더 명확하게 쓰고 싶을 때
7. 실행 계획을 체크리스트로 정리하고 싶을 때
8. 문제 보고 문서를 더 차분하고 정확하게 쓰고 싶을 때
9. 제안서를 읽는 사람이 바로 이해하게 고치고 싶을 때
10. 완성된 보고서나 기획서를 최종 검수하고 싶을 때

### 4.2 보조 5개
- 원하는 결과물 형식을 먼저 고정하고 싶을 때
- 빠진 핵심 요소가 있는지 점검하고 싶을 때
- 수정 요청을 어떻게 이어갈지 설계하고 싶을 때
- 검수 질문을 어떻게 던질지 정리하고 싶을 때
- 전체 작업 흐름을 한 번에 설계하고 싶을 때

---

## 5. 변수 반응형 기준
- 현재 막힌 부분
- 원하는 결과물 형식
- 사용할 AI 도구
- 원하는 톤/스타일

각 작업지시서는 위 변수를 흡수하는 슬롯과 보정 가이드를 포함해야 한다.

---

## 6. 판매 문구 방향

### 좋은 방향
- 상사 보고, 기획 문서, 실행안 정리를 더 빠르게 도와주는 작업지시서
- 실무자가 바로 복사해서 써도 어색하지 않은 문장 구조
- 보고부터 최종 검수까지 한 흐름으로 이어지는 패키지

### 피해야 하는 방향
- AI가 대신 보고서를 써준다
- 이 팩 하나면 보고가 무조건 잘 된다
- 복붙만 하면 끝난다

---

## 7. 최종 기준
업무/보고서 집중팩은 단순한 보고서 문장 모음이 아니라,
`실무 문서를 더 빨리 정리하고 더 신뢰감 있게 제출하게 도와주는 반응형 패키지`
처럼 느껴져야 한다.
